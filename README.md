# 콘티

찬양 인도자를 위한 콘티·송폼 도구. **설치 없음, 서버 없음, 파일 하나.**

악보 사진을 넣고 → 송폼 블록을 톡톡 누르고 → 글자를 손가락으로 끌어 놓으면
악보 여백에 송폼이 적힌 완성본이 PDF 한 개로 나옵니다. 카톡으로 보내거나 인쇄하세요.

## 여는 방법

**https://kgs1016.github.io/songform/** — 휴대폰이든 컴퓨터든 이 주소를 열면 됩니다.

휴대폰에서는 브라우저 메뉴의 **"홈 화면에 추가"** 를 누르면 앱처럼 쓸 수 있습니다.
다른 사람도 쓰게 하려면 이 주소만 보내주세요. (데이터는 각자 기기에 따로 저장됩니다)

컴퓨터에서 인터넷 없이 쓰려면 `index.html` 을 더블클릭해도 됩니다 (Chrome / Edge).

## 쓰는 순서

1. 홈에서 **＋ 주차 추가** → 예배 날짜
2. **＋ 악보 추가** → 악보 사진 넣기 (여러 장 고르면 한 장이 한 곡). 바로 제목 칸이 뜨니 악보 윗부분을 보고 적어주세요 — 나중에 목록에서 제목을 눌러도 됩니다
3. 곡 화면에서 블록 버튼을 순서대로 누르기: `Intro` `V1` `C` `V2` `C` `outro` …
   - 블록을 누르면 `×2 ×3` · 순서 이동 · 메모 · 삭제
   - **✨ 추천 받기**: 질문 4개에 답하면 초안을 만들어 줍니다
   - 주차 화면의 **✨ 전체 추천**: 20분 같은 전체 목표를 곡들에 나눠 한 번에 송폼을 짭니다
4. 악보 위 송폼 글자를 **손가락으로 끌어** 원하는 자리에 놓기, 아래 슬라이더로 크기 조절
5. **라벨 찍기**를 켜고 악보를 누르면 그 자리에 `V` `P.C` `C` 같은 빨간 라벨이 찍힙니다
6. **PDF로 내보내기** → 휴대폰이면 공유창에서 카톡 선택, 컴퓨터면 다운로드 폴더에 저장된 PDF를 카톡에 올리기. 인쇄는 주차 메뉴(⋯)에서

저장 버튼은 없습니다. 바뀔 때마다 자동으로 저장됩니다.

## 표기 규칙

`Intro-V1-P.C-C-V2-P.C-Cx2-inter(4마디)-Cx2-outro`

- 블록 사이는 `-`, 반복은 `x2`, 메모는 `(…)`
- `Intro` `inter` `outro` 같은 연주 구간은 자동으로 **빨간색**, 노래 구간은 검은색

## 데이터는 어디에 있나요

이 브라우저 안에 저장됩니다(IndexedDB). 다른 기기와 자동으로 공유되지는 않습니다.
기기를 바꾸거나 브라우저 데이터를 지울 일이 있으면 **설정(⋯) → 백업 파일 내려받기** 로 보관하고,
새 기기에서 **백업 파일 불러오기** 하세요.
