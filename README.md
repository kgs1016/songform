# 콘티

찬양 인도자를 위한 콘티·송폼 도구. **설치 없음, 서버 없음, 파일 하나.**

악보를 가져와 곡별로 묶고, 송폼을 적고, 전체 페이지를 확인한 뒤 PDF로 공유합니다.

## 여는 방법

**https://kgs1016.github.io/songform/**

휴대폰에서는 브라우저 메뉴의 **홈 화면에 추가**로 앱처럼 사용할 수 있습니다.
컴퓨터에서는 `index.html`을 직접 열어도 됩니다. 인터넷 연결 없이 사용할 수 있습니다.

## 작성부터 공유까지

1. **주차 추가**에서 예배 날짜를 선택합니다. 콘티 화면 상단 제목 또는 메뉴의 **콘티 제목 바꾸기**로 이름을 수정합니다.
2. **악보 추가**에서 사진을 선택합니다. 여러 장을 가져오면 **악보 묶기**에서 두 번째 장부터 **앞 장과 같은 곡**을 선택할 수 있습니다. 제목도 함께 적습니다.
3. 곡을 열어 송폼 블록을 누르거나 **직접 입력**으로 송폼을 작성합니다. 악보 위에서는 기본적으로 위아래 스크롤이 됩니다. 글자를 옮길 때는 **위치 편집**을 켜고 송폼이나 라벨을 직접 잡아 끌어 주세요. **위치 편집 끝** 또는 **스크롤로 돌아가기**를 누르면 스크롤 모드로 돌아옵니다. **실행 취소 / 다시 실행**은 현재 곡 편집 화면에서 최근 30개 편집을 지원합니다. 화면을 떠나면 이력은 초기화됩니다.
4. **전체 미리보기 · PDF 공유**에서 모든 페이지를 확인합니다. 각 페이지의 체크를 끄면 출력에서만 빠지고 악보는 남습니다. 송폼이 없는 뒷장도 기본적으로 포함합니다. 이미지를 누르면 넓게 볼 수 있습니다.
5. 파일 이름을 정하고 **PDF 다운로드**, **공유**, **인쇄**를 선택합니다. 공유를 지원하지 않는 브라우저에서는 PDF를 내려받아 카톡 등에 첨부합니다.

곡 화면에서는 **이 곡 PDF**와 **전체 PDF**를 구분합니다. 내보내는 파일에는 생성 시각을 붙입니다. 예: `10월 1주차 콘티_20261004_093012_123.pdf`. 같은 제목으로 다시 내보내도 이전 파일과 구분할 수 있습니다. 미리보기에서 확인한 이미지로 PDF를 만들며, 다시 열 때는 최신 편집 내용으로 새로 생성합니다.

콘티 화면에는 마지막 출력 파일과 이후 수정 여부가 표시됩니다. 다운로드는 브라우저에 요청하는 동작이므로 실제 파일 저장 여부는 브라우저 다운로드 목록에서 확인하세요.

## 찬송가 빠른 작성

곡 편집 화면의 **찬송가 작성**에서 부를 절을 고릅니다. 처음에는 1~4절이 선택되어 있고 **＋ 5절 추가**로 더 늘릴 수 있습니다. 후렴은 **없음 / 매 절 뒤 / 마지막만**, 전주·후주·절 사이 간주는 필요한 경우에만 선택합니다.

예를 들어 1·3·4절과 매 절 뒤 후렴을 고르면 `V1-C-V3-C-V4-C`가 됩니다. 선택한 절 사이 간주를 켜면 각 절의 후렴 다음, 다음 절 앞에 간주가 들어갑니다. 목표 시간 때문에 절이 빠지거나 브리지가 추가되지 않습니다.

**적용할 송폼**을 확인한 뒤 적용하세요. 취소하면 원래 송폼은 유지되며, 적용 후에도 기존 구간 편집과 **실행 취소**를 사용할 수 있습니다. 이 방식으로 작성한 송폼은 다시 열 때 현재 순서에서 선택값을 복원합니다. 반복·메모 등 사용자 편집을 포함해 이 양식으로 표현할 수 없는 송폼은 기본값으로 열고 현재 송폼을 따로 확인할 수 있습니다. 수동 블록과 악보 라벨에도 V3·V4를 제공합니다.

## 송폼 구간 선택 삭제

곡 편집 화면에서 **여러 개 선택**을 누르고 지울 구간들을 선택한 뒤 **선택한 N개 삭제**를 누릅니다. 같은 이름의 구간도 위치별로 따로 선택할 수 있습니다. **전체 선택 / 전체 선택 해제**를 지원하며, **선택 끝내기**는 송폼을 바꾸지 않고 선택 모드만 종료합니다.

일괄 삭제도 **실행 취소** 한 번으로 되돌릴 수 있습니다. 송폼을 수정하거나 다른 곡으로 이동하면 선택 모드가 종료되어 이전 선택이 다른 구간에 적용되지 않습니다.

## 악보 사진 추가

사진을 읽거나 변환하지 못하면 기존 악보를 그대로 유지하고 오류가 난 파일을 안내합니다. 여러 장 추가는 모든 사진을 읽은 뒤 한 번에 적용합니다. 추가 도중 다른 곡으로 이동하더라도 처음 선택한 곡에만 들어갑니다. 긴 스크린샷은 모바일에서 처리할 수 있는 크기로 축소합니다.

## 저장과 곡 재사용

변경 내용은 이 브라우저의 IndexedDB에 자동 저장됩니다. 화면 상단에 **저장 중 / 이 기기에 저장됨 / 저장 실패**가 표시됩니다. 실패 시 화면을 닫지 말고 **다시 시도**를 누르세요. 저장에 실패한 상태에서는 PDF를 내보내지 않습니다.

**보관함 원본과 각 콘티의 편집본은 독립적입니다.** 콘티를 복사하거나 같은 곡을 다시 추가해도 페이지, 송폼, 라벨, 위치를 수정하면 해당 콘티에만 적용됩니다. 기존 데이터는 처음 열 때 원본을 유지하면서 주차별 편집본으로 자동 전환합니다. 예전 구조에서 이미 덮어쓴 내용까지 복구하지는 못합니다.

주차에서 편집한 곡을 다시 쓰려면 곡 메뉴의 **편집본을 보관함에 새 곡으로 저장**을 선택합니다. 보관함과 곡 추가 화면에서 제목·키로 검색할 수 있습니다. 페이지 순서 이동과 장별 분리는 곡 메뉴에서 가능합니다.

## 곡별 송폼 재사용

- 이전 주차의 곡을 열고 **송폼 복사**, 다른 주차의 곡에서 **송폼 붙여넣기**를 누릅니다. 복사한 송폼은 이 브라우저에 보관되어 새로고침 후에도 사용할 수 있습니다. 기기 클립보드 복사를 지원하면 다른 앱에도 텍스트로 붙여넣을 수 있습니다.
- **이전 송폼 가져오기**에서는 주차별 송폼과 보관함을 검색할 수 있습니다. 같은 곡을 먼저 보여주고, 곡 제목·콘티 이름·날짜로 검색할 수 있습니다.
- 붙여넣기 화면에서 내용을 확인·수정한 뒤 **현재 송폼 바꾸기** 또는 **뒤에 이어 붙이기**를 선택합니다. 송폼만 바뀌고 악보·라벨·위치는 유지됩니다. **실행 취소**로 되돌릴 수 있습니다.
- 새 주차에 곡 자체가 없다면 **악보 추가 → 이전 콘티에서 곡 가져오기**로 개별 곡의 악보와 송폼을 함께 가져옵니다. 원래 콘티는 바뀌지 않습니다.
- 클립보드 읽기가 지원되지 않거나 허용되지 않으면 입력칸에 직접 붙여넣으면 됩니다. 앱 안에서 복사한 송폼은 별도 권한 없이 붙여넣을 수 있습니다.

## 백업

다른 기기·브라우저와 자동 동기화되지 않습니다. 기기를 바꾸거나 브라우저 데이터를 지우기 전에 **설정 → 백업 파일 내려받기**를 사용하고, 새 기기에서 **백업 파일 불러오기**로 복원하세요. PDF는 공유용 결과물이며 편집용 백업이 아닙니다.

백업에는 보관함, 주차별 편집본, 출력 제외 설정, 마지막 출력 정보가 함께 들어갑니다. 기존 버전 1 백업도 불러올 수 있습니다.

## 표기 규칙

`Intro-V1-P.C-C-V2-P.C-Cx2-inter(4마디)-Cx2-outro`

블록 사이는 `-`, 반복은 `x2`, 메모는 `(…)`입니다. `Intro`, `inter`, `outro` 등 연주 구간은 빨간색으로 표시됩니다.

## 개발 검증

프로그램 전체는 `index.html`입니다. `tests/regression.cjs`는 격리된 Playwright 브라우저에서 다음을 확인합니다.

- 기존 데이터 전환과 주차별 독립성
- 제목 수정, 송폼 편집, 실행 취소·다시 실행, 새로고침 후 복원
- 같은 제목으로 재다운로드 시 파일명·PDF 내용 갱신
- 출력 페이지 선택, 저장 실패 시 출력 차단과 재시도
- 여러 장짜리 악보 가져오기와 곡 검색, 백업 복원
- 곡별 송폼 복사·붙여넣기, 이전 주차 검색, 개별 곡 가져오기와 원본 보존

Playwright 설치 후 `node tests/regression.cjs`로 실행합니다. 시스템 Chrome을 사용하려면 `CHROME_PATH`로 실행 파일을 지정하세요. 테스트 결과와 PDF는 시스템 임시 폴더에 저장됩니다. `node tests/touch-import.cjs`는 모바일 터치 스크롤, 위치 편집·취소, 이미지 변환 실패, 추가 도중 곡 이동과 재시도를 검증합니다.

`node tests/bulk-selection.cjs`는 구간 여러 개 선택·해제, 일괄 삭제·실행 취소, 좁은 화면, 새로고침 후 빈 송폼 유지와 다른 주차·보관함 보존을 검증합니다.

`node tests/hymn-form.cjs`는 찬송가 절 선택, 후렴·연주 구간, 5절 이상 추가, 취소·실행 취소, 설정 복원, 저장·PDF와 원본 보존을 검증합니다.
